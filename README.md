# INITIAL D START LINE

頭文字D THE ARCADE を遊んだ記録を、運営者ひとりが書いていく非公式サイトです。掲示板や会員制度はありません。

## 方針

載せてよいのは、公式が公表している情報と、運営者自身が実際に確認したことだけです。

2026年9月2日に、初期表示として持っていた架空のデータをすべて削除しました。削除したのは、架空の投稿3件（投稿者名・いいね数・投稿時刻つき）、その投稿から算出していた「今週の参考になった投稿」と「初心者を助けたドライバー」のランキング、車種・コースの投票結果、月額応援メンバーとスポンサー掲載の案内、およびページ上に表示しなくなったFAQの構造化データです。実在しない利用者がいるように見せることになるためです。

同じものを再び追加しないでください。数字を置きたくなったら、その数字の出どころが公式か自分の記録かを先に確認します。

## 主な機能

- 運営者の現在の進捗を書く「いまの状況」
- 運営者が最初に覚えた順番（私見であることを明示）
- 収録コース・車種の名称一覧（性能の比較やおすすめ度は付けない）
- 閲覧者が自分用に記録するメモ（端末内のみに保存し、送信はしない）
- サイトマップ、robots.txt

## 開発

```bash
npm install
npm run dev
npm run build
npm run lint
```

本サイトは運営者ひとりのプレイ記録で、ファンによる非公式サイトです。ゲームメーカーおよび権利者各社とは関係ありません。
