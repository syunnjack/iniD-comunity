# INITIAL D START LINE

頭文字D THE ARCADEを始めたばかりのプレイヤー向けの、非公式攻略・成長記録・交流サイトです。

## 主な機能

- 最初の10プレイ向けロードマップ
- 初心者向けコース・車種ガイド
- localStorageへ保存する走行ログ
- 投稿、検索、カテゴリ絞り込み、いいね
- FAQ構造化データ、サイトマップ、robots.txt、llms.txt
- TOGE BASE BOOTHショップへの運営支援導線

## BOOTHショップ

サイト内のショップリンクは、未設定時も `https://toge-base.booth.pm/` を使用します。別URLへ切り替える場合は、公開環境に次の環境変数を設定します。

```env
NEXT_PUBLIC_BOOTH_URL=https://toge-base.booth.pm/
```

## 開発

```bash
npm install
npm run dev
npm run build
npm run lint
```

本サイトはファンによる非公式サイトで、ゲームメーカーおよび権利者各社とは関係ありません。
